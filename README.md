# holbertonschool-hbnb

## Project Overview

This is the second part of the HBnB project, focusing on implementing the core business logic and API endpoints. The project uses Python and Flask to build a modular application with a clear separation of concerns:

- Presentation Layer: RESTful API endpoints using flask-restx.
- Business Logic Layer: Core classes for Users, Places, Reviews, and Amenities.
- Persistence Layer: In-memory repository for object storage (to be replaced by a database in later parts).

This phase sets up the foundation of the application, preparing for further enhancements such as authentication and database integration.
